# Угадай дату — Локальная группа

Игра: показываем случайную картинку из паблика, игроки угадывают месяц и год публикации. Чем ближе, тем больше очков.

## Запуск
1. Создайте репозиторий на GitHub и загрузите туда всё содержимое этой папки.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/docs`.
3. Actions → «Обновить posts.json» → Run workflow. Через пару минут в `docs/posts.json` будут реальные посты (сейчас там 200 тестовых).
4. Сайт откроется по адресу `https://<ник>.github.io/<репозиторий>/`.

Другой канал: поменяйте `CHANNEL` в `.github/workflows/update.yml`.
Локально: `node scripts/scrape.mjs`, затем `npx serve docs`.

## Режимы
- Один игрок: 5 раундов.
- Комната на 2 или 4 игрока: создатель получает код, остальные вводят его. Создатель выступает сервером (WebRTC через PeerJS), он должен оставаться на странице.
